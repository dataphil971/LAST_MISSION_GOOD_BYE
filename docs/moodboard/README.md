# Moodboard

Dossier de references de travail. **Son contenu image n'est pas versionne**
(voir `.gitignore`) : une reference sert a regarder, pas a etre redistribuee.

Deux raisons, toutes deux bloquantes pour une publication :

1. **Licence.** Une image tiree d'un service de generation en ligne peut
   porter un filigrane commercial et des conditions d'utilisation
   incompatibles avec une republication.
2. **Coherence technique.** Les rendus « faux pixel art » suréchantillonnés
   (dessines en haute resolution puis reduits) violent frontalement la Bible
   d'art : densite de pixels incoherente, anticrenelage, contours flous.

Ce qu'on retient d'une reference, ce sont des **principes** — rapport
d'echelle entre personnage et decor, construction de la lumiere par zones,
composition par plans — jamais des assets.

Le fichier local `ref_ai_city_tileset_NON_UTILISABLE.jpg` est conserve comme
contre-exemple : vue de dessus (le jeu est de profil), filigrane visible,
pixels non natifs.
